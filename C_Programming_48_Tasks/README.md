# C Programming – 48 Tasks

This repository contains 48 C programming tasks organized into two parts.

## Part 1: Basic C Programs (1–24)

Programs 1–24 cover basic input/output, arithmetic operations, conversions, calculations, and simple programs.

## Part 2: Decision-Making Programs (25–48)

Programs 25–48 cover if-else, logical conditions, grading, eligibility checks, triangle classification, and switch-case programs.

## Files

Each task is stored in a separate `.c` file:

- `Task_01_...c` through `Task_48_...c`

## Compile and Run

```bash
gcc filename.c -o output
./output
```

For Task 20 (Compound Interest), which uses `math.h`:

```bash
gcc filename.c -o output -lm
```
